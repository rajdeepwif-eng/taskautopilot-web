## 2. What we capture on every enquiry (the brief)
1. **Result wanted** (customer's words) → matched to one of the 44 jobs below.
2. **How it works**: trigger → inputs → 3 steps (shown to the customer before they send).
3. **Today**: none / by hand / partly automated / software could do it.
4. **Tools** they use, **volume** per week.
5. **Route**: done for you / build with my team on n8n / DIY kit or course.
6. **Still to confirm** (the job's decision questions) — sent with the lead so the reply asks only these.

## 3. Build-ready checklist (before any n8n work starts)
- [ ] Trigger confirmed (event or schedule, time zone)
- [ ] 3 real examples of the input (redacted)
- [ ] Systems + access route (OAuth/API, read-only vs write) — customer connects their own logins, we never take passwords
- [ ] Field map: input field → where it goes
- [ ] Rules and exceptions (who to skip, limits, opt-outs)
- [ ] Human sign-off step for anything sent to customers or money moved (until they approve going automatic)
- [ ] Wording/tone approved
- [ ] Log so nothing runs twice; test mode; error workflow + missed-run check
- [ ] Owner named; how to undo written in the READ ME

## 4. How each enquiry is processed (target: reply within 1 working day)
1. Brief lands (website assistant → n8n webhook → Airtable "Enquiries" + Slack).
2. **Done it before?** Match the job id to our builds list → reuse the template and demo.
3. If their software already does it → tell them how to switch it on (free); offer the add-on only.
4. Reply with: how it works for them (from their "today" answer), the demo link, 3 routes with fixed prices, and only the unanswered questions.
5. Follow up day 2 and 5; book the setup form on yes.
